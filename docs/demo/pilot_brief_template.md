## 11. Safety gates

- [ ] 100% переданных результатов проходят human review.
- [ ] Внешнее исполнение, подача, ЭЦП и автоматическая отправка отключены.
- [ ] Tenant scope подтверждён.
- [ ] Передача разрешена только для текущего run и проверенного immutable PDF.
- [ ] Открытый Sev-1 блокирует передачу.
- [ ] Исправление утверждённого результата создаёт новый run.

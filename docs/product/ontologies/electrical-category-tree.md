# ARV-067B — иерархическое дерево электротехнических категорий

Статус: `RESEARCH_ASSET_READY`.

## Назначение

ARV-067B заменяет плоские строки `subcategories` из `nomenclature.v1.yaml`
версионируемым деревом со стабильными идентификаторами, явными родителями,
уровнями, путями, наследованием характеристик, маршрутными алиасами и
контролируемым жизненным циклом.

Дерево остаётся offline research asset и не подключено к production resolver.

## Структура дерева

В версии 1.0.0 зарегистрировано 166 узлов:

- 1 корень `electrical`;
- 2 реестровых узла: первичное и вторичное оборудование;
- 28 семейств, соответствующих 28 разделам номенклатуры Россетей;
- 135 подкатегорий, по одной стабильной записи на каждую исходную строку
  `subcategories`.

Каждый узел содержит:

- `category_id`;
- `parent_id`;
- `level`;
- полный `path`;
- `node_kind`;
- реестр `primary` или `secondary`;
- русское наименование;
- lifecycle status;
- маршрутные алиасы;
- локальные и наследуемые характеристики;
- явные overrides;
- provenance до исходного раздела и исходного наименования.

Основной файл `category_tree.v1.yaml` является манифестом. Узлы разделены на
16 проверяемых тематических фрагментов в `category_nodes/*.v1.yaml`.

## Стабильные идентификаторы

Идентификаторы не зависят от порядка строк и имеют форму:

```text
electrical.primary.switches.vacuum_circuit_breaker
electrical.primary.cables_fittings_pipes.power_cable
electrical.secondary.relay_protection_automation.protection_terminal
```

Переименование отображаемого названия не должно менять `category_id`.
Изменение идентификатора считается миграцией онтологии.

## Наследование характеристик

Семейство получает `local_refs`, равные `discriminator_attributes` исходного
раздела. Подкатегория наследует эффективный набор родителя и может:

- добавить `local_refs`;
- заменить наследуемую характеристику через `overrides`;
- сохранить ссылку на детальный профиль.

Четыре существующих детальных профиля привязаны к листьям:

- силовой кабель низкого напряжения;
- СИП;
- модульный автоматический выключатель;
- электромагнитный контактор.

Для контактора явно заменяются общие поля `rated_current_a` и
`rated_voltage_v` на ролевые `rated_operational_current_a` и
`rated_operational_voltage_v`. Это исключает скрытое объединение разных
электротехнических смыслов.

Все ссылки разрешаются только через ARV-067A.

## Маршрутизация

Offline router использует:

1. нормализацию регистра, `ё/е`, пунктуации и пробелов;
2. поиск алиаса по границам слов;
3. приоритет точного алиаса;
4. наиболее длинную последовательность слов;
5. наиболее глубокий узел;
6. приоритет узла.

Если одинаково сильные совпадения принадлежат разным ветвям, результат —
`UNCERTAIN`. Совпадение только с реестром или семейством получает
`FAMILY_MATCH` и всегда требует проверки.

Fixture-набор содержит 24 случая, включая:

- точные листовые маршруты;
- совпадения на уровне семейства;
- выбор длинного алиаса;
- межветвевую неоднозначность;
- отсутствие совпадения.

## Жизненный цикл

Последовательность продвижения:

```text
taxonomy_only
→ profile_draft
→ source_verified
→ fixtures_ready
→ benchmark_passed
→ shadow_runtime
→ operator_approved
→ production_active
```

Отдельный статус `deprecated` доступен на каждом этапе. Обратные переходы
между соседними этапами разрешены как контролируемый rollback.

В ARV-067B разрешены только `taxonomy_only` и `fixtures_ready`. Более высокие
статусы заблокированы до выполнения ARV-067H и ARV-067I.

## Проверка

```bash
python schemas/categories/electrical/validate_category_tree.py
python -m pytest -q tests/test_arv067b_category_tree.py
```

Ожидаемый маркер:

```text
ARV-067B category tree: OK (nodes=166, families=28, subcategories=135, detailed_profiles=4, routing_cases=24, runtime_import=false)
```

Валидатор проверяет:

- закрытые схемы манифеста и фрагментов;
- уникальность IDs;
- отсутствие циклов и orphan nodes;
- согласованность `parent_id`, `level` и `path`;
- полный перенос 28 разделов и 135 подкатегорий;
- сохранение исходных наименований и алиасов;
- существование всех характеристик в ARV-067A;
- корректность overrides;
- покрытие всех четырёх детальных профилей;
- допустимые lifecycle statuses;
- коллизии алиасов;
- fixture routing;
- отсутствие production import.

## Границы

- production resolver не изменён;
- БД и миграции не изменены;
- дерево не формирует нормативное заключение;
- taxonomy-only узлы не становятся production matchers;
- family match и ambiguity требуют review;
- модели производителей не включены;
- shadow runtime не подключён.

Маркеры результата:

- `ARV-067B_CATEGORY_TREE_READY`
- `ARV-067B_ALL_28_FAMILIES_MAPPED`
- `ARV-067B_ALL_135_SUBCATEGORIES_STABLE`
- `ARV-067B_ATTRIBUTE_INHERITANCE_VALIDATED`
- `ARV-067B_PRODUCTION_RUNTIME_NOT_WIRED`

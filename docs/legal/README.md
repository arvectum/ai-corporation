## Обязательная граница

Документы не открывают автоматическую подачу, ЭЦП, supplier outreach, вход в личные кабинеты, скрытую передачу внешнему LLM или исключительно автоматизированное юридически значимое решение.

До первого внешнего акцепта/подписания обязательны:

- утверждение генеральным директором;
- проверка квалифицированным юристом по праву РФ;
- сверка уведомления Роскомнадзора с фактическим контуром;
- подтверждение локализации первичного сбора;
- заполненный pilot brief и письменный режим обработки/LLM;
- проверяемая процедура удаления и backup-retention.

Собранные DOCX/PDF являются релизными артефактами ARV-041 и формируются из этих канонических текстов. Бинарные файлы не должны заменять источники и историю решений.

# Визитка Arvectum

Канонический утверждённый макет двусторонней визитки генерального директора ООО «Арвектум».

## Зафиксированный вариант

- формат после обрезки: **90 × 50 мм**;
- русская сторона: светлое поле, узкая полоса Deep Navy и акцент Mint Primary;
- английская сторона: поле Deep Navy, узкая белая полоса и акцент Mint Primary;
- официальный фирменный блок **AV + Arvectum** сохранён без изменения начертания и пропорций;
- дескрипторы: `ИИ-АВТОМАТИЗАЦИЯ` / `AI AUTOMATION`;
- QR-код отсутствует;
- контактные подписи заменены пиктограммами конверта, глобуса и телефона.

## Файлы

- `arvectum-business-card-ru.svg` — русская сторона;
- `arvectum-business-card-en.svg` — английская сторона;
- `render-assets.sh` — генерация PNG и PDF через Inkscape.

SVG имеют физический размер 90 × 50 мм и `viewBox` 900 × 500. Фирменный логотип встроен в виде оригинальных векторных контуров из исходников бренда.

## Типографика

- основной текст и заголовки: **PT Sans**;
- технические подписи и дескрипторы: **JetBrains Mono**.

Шрифтовые файлы в репозиторий не включаются. Перед рендерингом они должны быть установлены в системе.

## Рендеринг

```bash
cd docs/brand/business-card
bash render-assets.sh
```

Скрипт создаёт в каталоге `dist/`:

- полноразмерные PNG 1530 × 850 px;
- облегчённые PNG для почтовой подписи 900 × 500 px;
- PDF каждой стороны.

При дальнейших изменениях запрещено заменять фирменный логотип стилизованной надписью или иной эмблемой.
